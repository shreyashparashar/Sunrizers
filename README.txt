SUNRIZERS ENGINEERS - WEBSITE FILES
===================================

Open index.html in any browser to view the site.
To go live, upload ALL files and folders (css, js, images and every .html file)
to the public_html folder of your sunrizerssengineers.in hosting.

THINGS TO REPLACE BEFORE GOING LIVE
1. Address and GSTIN are still placeholders: edit in every .html file.
   (Phone number is already set to +91 99645 56263 site-wide.)
   Use Find and Replace across all files.
2. Google Map: in contact.html, replace the iframe src with your own
   Google Maps embed link.
3. Machinery list in infrastructure.html: edit to match your actual machines.
4. Enquiry forms use mailto: (opens the visitor's email app). For a proper
   form, connect a form service or a PHP mail script on your hosting.
